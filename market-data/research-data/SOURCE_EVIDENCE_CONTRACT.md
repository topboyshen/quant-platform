# research-data 来源证据封存与补偿契约

日期：2026-09-07；状态：后续实施契约草案，未部署。

本文件仅定义设计与验收边界；未修改 VPS、采集器、调度、数据库或备份配置。
权威基线为本地 `outputs/research-data-cninfo-fix/daily_snapshot.py` 与同目录 `README.md`。
除“当前实现”明确列出的行为外，下述封存、补偿与异地复制均是待实现要求。

## 1. 当前实现与不可改变的边界

- 当前仅处理本地 Qlib 最新完整交易日，不接受历史日期参数。
- 目前只有 AkShare 市场截面具备独立不可变封存；其他来源成功结果通常只存在于当次内存或成功快照。
- AkShare 截面包含活跃度和行业摘要；封存日期由活跃度“统计日期”确定，行业摘要没有独立日期字段。
- 任一关键来源最终失败均拒绝快照；已有快照不得覆盖，来源门禁不得因重试而放宽。
- 当前对实时及滚动来源只记录整体采集时间窗，不等于每个请求已有精确采集时间。
- `sourceAsOf.akshareStage` 是封存权威元数据；兼容列表仍含 `akshareSectors`，不能据此忽略封存时间窗。
- `FROZEN`、AStock `DRAFT_ONLY`、外发门禁与业务写入 timer 均不由本契约改变。

## 2. 时间语义与历史可重建性

`trade_date` 表示数据所描述的交易日；`observed_at` 表示系统实际取得数据的时间。
请求中的日期、接口返回的日期、公告发布时间和采集时间必须分别保存，不能相互替代。
今天取得的历史数据也必须记录今天的 `observed_at`；不得倒填成昨天或上游发布日期。
只有整体时间窗的旧记录应原样保留，并标明 `timestamp_precision=run_window`，不得伪造逐源时间。

| 来源 | 当前时间语义 | 历史补偿边界 |
|---|---|---|
| Qlib 量价 | `trade_date`；同代目录、release tag 与完整性校验 | 历史特征是否齐全需独立验证；保留 generation、包摘要及解析器版本，不能只凭最新 tag 宣称历史可恢复。 |
| AkShare 活跃度 | 返回的“统计日期”；附真实封存窗 | 优先复用已校验同日封存；当前实时接口不是历史证明。 |
| AkShare 行业摘要 | 与活跃度同次封存，未独立返回日期 | 不把活跃度日期当作每条板块记录的独立证明；历史复用需保留同次来源和时间窗说明。 |
| AkShare 新浪龙虎榜 `lhb` | 按 Qlib 目标日查询，包装结果含日期 | 需独立确认返回数据日期、覆盖范围及合法空结果；请求参数不是完整性证明。 |
| 交易所龙虎榜 `lhbOfficial` | 按目标日请求沪深披露 | 保留各交易所独立来源、日期及成功状态；历史结果需重新验证，不能以另一市场替代失败市场。 |
| 全 A 实时现货 `spot` | `date=current`，`observed_at` | 无当时封存不得重建昨日截面；同样适用于涨停衍生证券集合。 |
| 新浪资金流 `fundFlow` | 最近 5 条滚动记录含各自日期，整体 `observed_at` | 历史日期行不等于当时滚动窗口；需验证查询范围、修订及证券覆盖，不能裁剪后冒充当时观察。 |

| Baostock 估值 `baostock` | 截至采集当天的滚动历史，行内含日期 | 历史查询能力、复权和修订语义需独立证明；采集时间仍为实际补采时间。 |
| 巨潮公告 `announcements` | 当前查询返回的公告列表，整体 `observed_at` | 公告日期不等于当时已知集合；历史回建需证明分页完整、发布时间与修订，不等同复刻当日首页。 |
| 财联社电报 `news` | 最新滚动 20 条，记录新闻时间与 `observed_at` | 事后查到旧新闻不能证明当时完整可见集合；无原封存不得伪造。 |
| 北向数据 `northbound` | 当前日内序列摘要，当前结果未保留来源日期 | 只认真实采集窗；无独立历史日期证据不得绑定目标日。 |

历史来源能够重查不代表已经允许生产补跑；历史输入适配、离线复原与人工授权仍是独立门禁。
若历史包缺少当时的实时来源，应保留缺口；研究性重建只能另建明确标注的产物，不能冒充原快照。

## 3. 封存对象与 manifest 最小字段

建议以“来源／证券或市场／一次观察”为最小不可变对象，以内容摘要寻址。
同一次快照由独立 assembly manifest 引用对象，不把所有来源绑成一个必须全成功的文件。

- `schema_version`、`evidence_id`、`run_id`：版本、对象身份与原始采集运行身份。
- `source_id`、`source_partition`：来源及证券/市场分区；分区完整性不得被总来源成功状态掩盖。
- `collector_commit`、`parser_version`、`validation_policy_version`：采集与解释规则的可复现版本。
- `request_scope`：允许列表中的请求日期、证券、分页与条数；保留配置摘要及证券集合证据。
- `target_trade_date`：组装目标，可为空；不得覆盖来源自身统计日期。
- `source_trade_dates`、`source_published_at`、`source_timezone`：来源提供的真实时间信息，未知明确为未知。
- `collection_started_at`、`collection_completed_at`、`observed_at`、`timestamp_precision`：带时区的实际时间及精度。
- `status=validated`、`coverage`、`expected_partitions`、`present_partitions`、`truncated`：校验与范围声明。
- `content_type`、`encoding`、`payload_bytes`、`payload_sha256`：封存 payload 的精确字节身份。
- `canonicalization_version`、`manifest_sha256`：严格 JSON 规范化规则；计算 manifest 摘要时排除自身摘要字段。
- `transport_security`、`provenance`：传输验证情况及来源依据；内容哈希只能证明未变化，不能证明来源真实性。
- `parent_evidence_ids`、`qlib_generation`：派生依赖与 Qlib 代际证据；不适用时明确为空。
- `sealed_at`、`privacy_class`、`retention_class`：封存时刻、访问等级与保留分类。

manifest 不得包含凭证、Cookie、Authorization、代理密码、签名参数、原始异常或完整带查询串 URL。
原始字节与规范化 payload 若同时保留，应分别命名并计算摘要，不能拿一种摘要声称校验另一种。
manifest 自身 SHA 不是数字签名；抗恶意篡改需结合独立副本、对象版本和独立身份，不夸大保障。

## 4. 成功来源与失败状态分离

- 单个来源分区校验成功即独立封存；公告中一只证券失败，不应丢掉其他证券已成功的证据。
- 父来源仍可为 `incomplete`；已封存部分不能被当成完整集合绕过快照门禁。
- 失败仅追加 attempt 记录：运行、来源、分区、真实时间、错误分类、次数、可公开 HTTP 状态。
- 失败对象不得使用 `validated`，不得把错误正文、错误页或空列表伪装成成功 payload。
- 明确的上游合法空结果才是有效空数据；超时、403、分页缺失都不是“没有数据”。
- 同内容幂等；同来源范围不同内容建立新观察版本/冲突记录，不覆盖原对象或旧快照。
- 缺口台账记录目标日各来源缺什么；后一天成功不能清除前一天尚无证据的缺口。

## 5. 隐私、容量与过期边界

- 目录 `0700`、文件 `0600`、校验拥有者并拒绝符号链接；使用原子发布及发布后哈希验证。
- 研究证券集合和 F10 文本按私有研究数据处理；默认只封存必要的规范化字段，不扩大原文抓取范围。
- 当前 AkShare 封存上限为 4 MiB；新增来源需单独定上限，HTTP 读取过程也应限流量而非下载后才检查。
- 初始原型可用 JSON 单对象 4 MiB、manifest 64 KiB 的保守上限；不足应显式拒绝并评审，不静默截断。
- 当前 F10 已截断，应按既有范围诚实标注；不得把截断对象计入“原文完整”覆盖率。
- 磁盘预算、每日期对象数、压缩解包上限均需部署前定量核算；触顶报警，不能自动删未复制证据腾空间。
- 当前交易日有效性、供组装的时效和审计保留期是三个概念；过时数据仍可能需要长期审计保留。
- 建议原型活跃补偿窗为 7 个交易日，超窗转人工审阅而非自动删除；待缺口仍有未决引用时禁止自动回收。
- 保留期与云生命周期必须经过容量及用户目标确认；本草案不授权清理任何历史文件。
- 现有 `lhbOfficial` 深交所请求关闭证书校验、`hotStocks` 使用 HTTP，尚不具备完整传输身份保障。
  新封存验收须显式标注这些限制并另行审查；本次不改网络或采集代码，哈希不能消除该风险。

## 6. 补偿与异地保存的实施门禁

- 离线补偿只读取通过 manifest、payload 和时间语义校验的不可变对象，不调用外部模型或业务写入。
- 新采集与旧输入重放分开；补采不改真实 `observed_at`，不能复用今天数据假充旧日实时截面。
- 在隔离临时数据库证明日期覆盖、来源完整、同内容幂等、冲突拒绝、旧行摘要不变后，才评审生产方案。
- 未来重试应有总超时、次数上限、互斥锁与单一调度入口；失败关闭，不自动解除冻结。
- 每个已封存成功对象可独立进入异地复制队列，不依赖最终快照是否 `inserted`。
- 同次公告失败不能阻断 Qlib、AkShare 或其他已验证来源的异地保存；失败状态也作为独立审计记录复制。
- 复制回执单独追加，含对象 ID、云对象版本、远端校验依据、实际完成时间；不修改原封存 manifest。
- COS/本地目标、地域、容量、加密、保留期及访问身份尚需确定；当前没有新建桶、上传数据或创建备份。
- 上传身份不得删除历史版本；复制失败只重试复制，不重复采集或重跑生产快照。
- 验收应包含“快照失败但成功来源已异地可恢复”和“缺少一个来源仍拒绝组装”两项故障注入。
- 最终恢复演练验证来源对象、manifest、配置版本与数据库的一致性；恢复环境默认不外发、不启动冻结任务。
