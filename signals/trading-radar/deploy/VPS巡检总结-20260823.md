2. updater 仅接受四个唯一 symbol、同一 `expected_as_of`、有限正数 close 的完整批次。
3. Tencent 精确日期缺失时才逐 symbol 回退 Sina；任一失败保留 last-known-good。
4. updater 工作日 15:35 运行，digest 15:40/整点消费缓存；两者均 `Persistent=true`。
5. integration 新镜像以运行中的精确 image ID 为基底，仅加入 smoke 脚本并 `py_compile`。
6. 仅重建 integration-api；其他八个容器不得变化。
