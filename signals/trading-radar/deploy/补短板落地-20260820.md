### 1. Quant 第二行情源（CNStock 日线）

**问题**  
Quant 回测依赖腾讯单点；JD Filter 收盘已有腾讯 → 新浪双源，但 Quant 自己没有。

**方案**  
在 `~/QuantDinger/backend_api_python/app/data_sources/cn_stock.py` 加 **Tier 2.5 Sina daily**：
- Twelve Data（付费，优先）
- Tencent 日/周线（快、免费）
- **Sina 日线**（新增，腾讯失败后自动切）
- yfinance
- AkShare

**验证**
```python
from app.data_sources.cn_stock import CNStockDataSource
ds = CNStockDataSource()
rows = ds.get_kline("sh000001", "1D", 5, None, None)
# 返回 5 条，last close 3905.23
```

`cn_stock.py.bak` 已备份；改动已 docker cp 进 `radar-quantdinger-backend` 容器。
